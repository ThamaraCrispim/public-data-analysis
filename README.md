# Public Data Analysis | Portfólio de Análise de Dados

Repositório dedicado a projetos de análise de dados desenvolvidos em Python a partir de bases públicas.  
O objetivo é investigar problemas reais, gerar insights e demonstrar como dados podem apoiar decisões e compreensão de fenômenos sociais, econômicos e operacionais.

Este portfólio representa a aplicação prática de técnicas analíticas em contextos reais, utilizando dados abertos como fonte para exploração, interpretação e construção de narrativas orientadas por evidências.

---

## Propósito do Repositório

Este projeto foi criado para:

- Aplicar análise exploratória de dados em cenários reais  
- Trabalhar com bases públicas de diferentes domínios  
- Desenvolver pensamento analítico e interpretação orientada por dados  
- Documentar processos analíticos de forma clara e reproduzível  
- Demonstrar evolução técnica em projetos de dados utilizando Python  

Mais do que exercícios técnicos, os projetos buscam evidenciar como dados públicos podem ser transformados em informação relevante para compreensão de problemas e apoio à tomada de decisão.

---

## Abordagem Analítica

Cada projeto segue uma estrutura analítica baseada em práticas de mercado:

1. Entendimento do contexto e definição do problema  
2. Exploração inicial do dataset  
3. Limpeza e tratamento de dados  
4. Análise exploratória e identificação de padrões  
5. Construção de visualizações  
6. Interpretação dos resultados  
7. Geração de insights e conclusões  

O foco está em transformar dados brutos em análises estruturadas e interpretáveis.

---

## Fontes de Dados

Os projetos utilizam dados abertos provenientes de fontes institucionais e governamentais, como:

- portais de transparência pública  
- instituições governamentais  
- bases estatísticas oficiais  
- conjuntos de dados disponibilizados para pesquisa e acesso público  

O uso de dados reais permite simular cenários próximos aos enfrentados por profissionais de dados no mercado.

---

## Tipos de Projetos Desenvolvidos

As análises contemplam diferentes áreas e contextos, como:

- segurança pública e mobilidade  
- indicadores sociais e econômicos  
- dados administrativos governamentais  
- análises com séries temporais  
- comparações entre períodos e regiões  

Cada projeto busca responder perguntas analíticas e gerar interpretações relevantes a partir dos dados.

---
